# Contributing to fulfillmenttools commercetools Connect app

Thanks for your interest in contributing to the fulfillmenttools commercetools Connect app!

Review this document to make the contribution process easy and effective for everyone involved.

Following these guidelines shows you respect the time of the developers managing and developing this open source project. In return, they'll reciprocate that respect in addressing your issue or assessing patches and features.

## Reporting new issues

We use [GitHub issues](https://github.com/fulfillmenttools/commercetools-connector/issues) for our public bugs. If you'd like to report a problem, check whether someone already opened an issue about it. If you're sure this is a new unreported bug, you can submit a bug report.

## Submitting a pull request

Good pull requests, such as patches, improvements, and new features, are a fantastic help. They should remain focused in scope and avoid containing unrelated commits.

Please ask first whether someone else is already working on this or whether the core developers think your feature is in scope for the related package or project. Generally, always link to a related issue and include discussions for whatever you are including.

Also provide a test plan, for example, specify how you verified that your addition works.

Adhere to the coding conventions used throughout a project (indentation, accurate comments, and so on) and any other requirements (such as test coverage).

## Setting up a local copy

1. Clone the repo with `git clone git@github.com:fulfillmenttools/commercetools-connector.git`
1. Run `nvm use` and `npm install`
1. Use `npm run build`, `npm run test`, and `npm run lint` to make sure your modifications can be compiled and all tests are green.

### Coding conventions

We use [ESLint](https://eslint.org/), [Prettier](https://prettier.io/), and [EditorConfig](https://editorconfig.org/) for consistent coding style and formatting.

## Questions

If you have any questions about our process, how to proceed, or anything else, contact us at [opensource@fulfillmenttools.com](mailto:opensource@fulfillmenttools.com).
